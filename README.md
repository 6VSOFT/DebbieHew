# Debbie Hew · Personal brand landing page

A responsive Chinese landing page for 中华睡眠养生关怀咨询师 Debbie Hew. Built with HTML, CSS and JavaScript, with no build dependencies.

## Preview

Run `python -m http.server 4173 --bind 127.0.0.1` from the repository, then open http://127.0.0.1:4173.

## Publishing

GitHub Pages serves the `main` branch, `/ (root)`. Site: https://6vsoft.github.io/DebbieHew/

All asset paths are relative so the site works under the repository's `/DebbieHew/` path. Changes to `main` are automatically published by GitHub Pages.
